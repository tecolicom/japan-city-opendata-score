# japan-public-data-index

全国の自治体が web で発信する情報が「実際に使えるか」を、実測で評価する知識ベース。

> 骨のみ。方針と構成は後続タスクで書き足す。

## 方針

- 実測した事実を記録する。測れなかったものは `unknown` とし、0 点にはしない。
- 合算した総合点は作らない。軸ごとに見る。
- 軸の継承 (市区町村 → 配下) は A / F / G のみ。

## 使い方

```
make setup   # 依存を入れる
make test    # 全ゲート
```
